# Product

## Register

product

## Users

Media enthusiasts who track what movies, TV shows, anime, games, books, comics, and other media they've consumed across interconnected franchises and universes. They care about completeness, release order, and discovering connections between media they already love. Their context: browsing on desktop or mobile, often after finishing a movie/game, wanting to log it and see what else belongs in that universe.

## Product Purpose

Lore is a media tracking platform that organizes media into "universes" — curated collections of every official item in a franchise, ordered by release date. Users can see what they've watched/played/read, what's next in a universe, and discover new media through trending feeds across 10+ media types. Success = users can navigate a franchise's complete timeline and track their progress through it without gaps.

## Brand Personality

Clean, data-focused, honest. The interface gets out of the way and lets the media content speak. Think Letterboxd's restraint, not a streaming service's splashy thumbnails. Three words: precise, calm, complete.

## Anti-references

- Generic SaaS landing pages with gradient text, fake social proof (stock avatars, inflated user counts, 5-star ratings), and identical card grids repeated across sections.
- Cluttered, ad-heavy entertainment sites that bury content under promotional noise.
- Marketing pages that overpromise and underdeliver — the UI should reflect what the product actually does, not sell a fantasy.

## Design Principles

1. **Content first, chrome second.** Media posters, titles, and metadata are the product. The UI frame should be minimal enough that users forget it's there.
2. **Honest defaults.** No fake stats, no placeholder social proof, no gradient text. If we don't have a number, don't invent one.
3. **Completeness as a feature.** Universes are exhaustive by design. The UI should make "X of Y items tracked" visible and satisfying, not hidden behind marketing copy.
4. **One rhythm, not ten.** Avoid repeating the same component pattern (card grid + heading + CTA) across 10 sections. Vary the layout to match what each section actually shows.

## Accessibility & Inclusion

- WCAG AA target (4.5:1 contrast for body text, 3:1 for large text).
- Keyboard navigation for all interactive elements.
- Reduced motion support for animations.
- Alt text on all media posters (already handled via title attributes).
